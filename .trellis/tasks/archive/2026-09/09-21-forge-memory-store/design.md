# 设计：长期记忆数据库与迁移

父任务 design.md 是共享存储/状态/检索协议。
## 边界
MemoryStore、schema 迁移、版本/来源/事件/关系/作用域、中文 FTS5、在线备份恢复和 Markdown 导出。
读工具不因查询创建或迁移数据库；数据库不可读明确诊断，不静默视为空库。
幂等导入旧 vault/反馈，保留 user_owned 与禁用状态，unknown 项目隔离。
## 一致性与失败
模型调用在事务外；版本、事件和投影在事务内。后台更新检查当前版本，不能覆盖较新的人工纠正。
记录可观测诊断，未知证据不升级为 verified；只读查询不初始化或迁移库。
## 回滚
产品数据更新保留版本与来源，迁移使用在线备份恢复；FTS 可重建，权威 memory.db 不可直接丢弃。子任务撤销不能丢掉后续合法纠正。

## 持续学习协议
来源、版本、认知角色、适用条件和版本化证据关系。条件 unknown 与 false 分开；索引派生可重建，权威库备份可恢复。
共享语义遵循父任务 design.md。不能通过提高模型自评分或增加条目数量宣称学习成功。
