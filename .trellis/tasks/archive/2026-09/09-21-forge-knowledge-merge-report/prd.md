# 自动记忆整理与解释报告
## Goal
自动记忆整理与解释报告，遵循父任务自动运行、人工可纠正的总协议。
父任务：.trellis/tasks/09-21-forge-recall-rank-and-merge
## Dependencies
09-21-forge-memory-store、09-21-forge-memory-lifecycle。
## Requirements
数据库自动治理与只读 report 分开；不再只做人工审核报告。
完全重复且范围兼容可自动 canonical 去重；近似提案允许复用模型，不能保证来源/含义保全时自动保留分立，不等人工。
规则项目隔离；知识可离线全局比对但不扩大在线访问范围。路径前缀是可能重叠启发式，不能冒充 glob 集合交证明。
相似度不证明同义/矛盾，冲突关系需依据；不可仅凭时间认定替代。支持撤销、拆分、旧 id 解析。
报告展示重复、重叠/冲突疑点、过宽观察与依据；同一库快照/参数确定，无结果明确输出。
## Acceptance Criteria
- [ ] 正反样例：重复、否定、条件差异、跨项目/版本、同义异词 的正常、边界及故障测试通过。
- [ ] bigram 候选＋模型可选整理；阈值按质量标定，不强求 10–60 对 的正常、边界及故障测试通过。
- [ ] 版本比较、事务应用、来源保全、范围不扩大、纠正优先 的正常、边界及故障测试通过。
- [ ] 只读报告、空统计与失败区分、哈希/mtime 的正常、边界及故障测试通过。
- [ ] 无人审核运行、模型失败保留原文、冲突分立、撤销 的正常、边界及故障测试通过。
- [ ] python -m pytest tests/ -q 通过。
## Out of Scope
模型参数训练、专用向量服务、强制人工审批。

## 持续学习定位下的职责
整合目标是减少冗余并保留决策边界。支持/反驳/例外/细化不被简单去重吞掉；相似度只找候选，未决冲突保持分立；独立报告解释变化依据。
### 新增验收
- [ ] 关系与反证不因归并丢失；跨范围不外推；无新证据可保持不更新；整理可逆且有质量评估。
