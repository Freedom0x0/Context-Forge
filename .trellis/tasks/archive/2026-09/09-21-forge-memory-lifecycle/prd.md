# 自动记忆生命周期与人工纠正
## Goal
自动记忆生命周期与人工纠正，遵循父任务自动运行、人工可纠正的总协议。
父任务：.trellis/tasks/09-21-forge-recall-rank-and-merge
## Dependencies
09-21-forge-memory-store。
## Requirements
复用 SessionArtifacts/worker/模型网关，不从零重复建设提炼。每会话零到多条候选，按需派生规则。
价值、可信度、风险独立判断；无人审批自动运行，模型失败重试/死信可见。
支持 suppress/restore/revise/scope/supersede/split/撤销；纠正使旧派生规则失效。

- [ ] 候选结构、证据校验、模型/提示词版本 的正常、边界及故障测试通过。
- [ ] 跨库幂等发布和模型失败恢复 的正常、边界及故障测试通过。
- [ ] 纠正接口、后台版本竞争、派生规则失效 的正常、边界及故障测试通过。
- [ ] 零/多候选、无人运行、重新提炼不复活抑制、删除策略 的正常、边界及故障测试通过。
- [ ] python -m pytest tests/ -q 通过。
## Out of Scope
